# File: `lessons.html`

## Overview
This is the HTML interface for the AI Study Lessons feature. It provides a two-view structure: a dashboard listing all generated lessons, and a detail view where a selected lesson's markdown content is rendered into readable HTML.

## Key Logic & Structure

### Header Section
- **Lines 17-46**: Top navigation header.
  - Contains a "Back to Dashboard" link.
  - Houses the standard Accessibility and Account Dropdown menus (injected dynamically).

### Main Container
- **Line 48**: The `<main>` wrapper holding the two conditional views.

#### List View (`#list-view`)
- **Lines 50-64**: The default active view.
  - Contains the `#lessons-container` grid.
  - `lessons.js` fetches the user's generated lessons from Firestore and injects `.plan-card` HTML elements into this container on page load. It defaults to a "Loading lessons..." message.

#### Detail View (`#resultsSection`)
- **Lines 67-87**: Hidden by default. Activated when a user clicks on a lesson card.
  - **Lines 68-76**: A sub-header containing a `#back-from-detail-btn` to return to the list view, and a dynamic `#lesson-detail-title`.
  - **Lines 78-80**: The `#lessonContent` container. It includes the `.markdown-body` class to apply specific typography styles. The JS uses `marked.js` to inject the parsed HTML into this div.
  - **Lines 82-86**: Contains the `#finishBtn`. Clicking this updates the user's metrics in Firestore and marks the lesson complete.

### External Scripts & Dependencies
- **Lines 9-12**: Imports essential third-party libraries via CDN:
  - `marked.min.js`: A markdown parser used by `lessons.js` to convert the raw text generated by the AI into formatted HTML elements (headers, lists, bold text, etc.).
  - `html2pdf.bundle.min.js`: Included for potential PDF exporting (though not currently utilized in the `lessons.js` script).
- **Lines 90-92**: Loads internal scripts: `firebaseAuth.js`, `lessons.js`, and `settings.js`.
